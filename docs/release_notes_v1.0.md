English fan translation of **Vattroller X** (Game Boy Advance, Bandai, 2004; developed by Ganbarion).

Download `Vattroller_X_EN_v1.0.zip`, then apply the `.bps` inside to your own dump of the Japanese
cartridge with any BPS patcher (Floating IPS, beat, or [RomPatcher.js](https://www.marcrobledo.com/RomPatcher.js/)).
The zip's README has the details.

**What's translated:** the story and dialogue (comic mode, RPG mode, side events, town NPCs), menus, items, Arms,
Armalets, V Skills, shops, system messages, graphics with text (menu labels, help bubbles, world-map labels, signs,
book spines, rule cards), the name entry (Latin keyboard pages replace the kana pages) and the credits roll. The
title logo and the Ganbarion boot logo stay in Japanese.

**Known issues**
- Link-cable features (multiplayer battles, V Skill trading) could not be tested.
- Some short labels are abbreviated to fit their fixed-width boxes.
- The patched ROM is larger than 16 MiB. This is expected.

Please report bugs, with a savestate if you can, in [Issues](../../issues). Start from a cold boot, not from a
savestate made with another version.
