# Skill gotchas

One line per gotcha: the reference file it belongs in, then the fact.

- references/pipeline.md §Checks: `romdiff.py --writes` wants `OFFSET ORIG_HEX NEW_HEX` lines, but a build that logs (start, end, writer) ranges must convert them (orig/new bytes per range) and add its own per-writer region rule; `tools/romcheck.py` here does both and runs inside build.py. Worth shipping as a skill helper.
- references/translation.md §Review: `codex exec` reviewers of ROM strings flag every width-forced abbreviation; append a note with each line's char limit and the display order of reflowed/interleaved descriptions to the prompt, or they suggest wordings that cannot fit.

- references/setup.md + scripts/fetch_emu.py: `fetch_emu.py gba-bios` 404s; retrobios moved the file to `bios/Nintendo/Game Boy Advance/GBA_bios.rom` (same SHA-1 300c20df...).
- SKILL.md Step 0: plugin hook did not fire on Windows/Orca; adding the hooks block with `$HOME/.claude/plugins/marketplaces/...` to .claude/settings.json made it live mid-session.
- references/emulator-qa.md §Hooks: Mesen GBA Lua has `emu.read`/`emu.read16`/`emu.read32`/`emu.write`/`write16`/`write32` but no `read8`/`write8`; GBA registers are `emu.getState()["cpu.r0"]`..`["cpu.r15"]`.
- references/emulator-qa.md §emu.py: emu.py's `--mash` presses one key; games whose choice boxes start with nothing selected need a direction then A (this repo: tools/lua/mash2.lua). A mash script queuing L.press also fights any other script that waits on L.route_done().
- references/emulator-qa.md §Debug tool: for room-based games, the cheapest warp is swapping the room id at the loader's read (on_exec just before the ldrsh) plus script teleport ops for entry coordinates; a story script running when the room is swapped keeps running in the new room.
- references/pipeline.md §Extract: Python cp932 decodes 0x80/0xA0/0xFD-0xFF to the Private Use Area and IBM-extension duplicates (桒 FA E3) re-encode to the NEC code (ED 93); a decoder must emit [XX] for any char that does not re-encode to the same bytes, or the roundtrip test catches it late.
- references/setup.md: the template .gitignore's unanchored `rom/` also ignored `script/rom/` (the ROM-string scripts went uncommitted through phase 4); anchor it as `/rom/`.
- references/pipeline.md §Marker: a pointer scan picks up a TABLE BASE whose first record is text (credits table 0x74570: code adds index*0x2C to the literal) as a pointered string; repointing it for the marker moved the whole table and the credits stopped drawing. Cross-check pointered-string ids against fixed-record tables; bisect a broken scene by kind (`tools/exp_build.py --orig string`).
- references/pipeline.md §Marker: strings of only fullwidth spaces are blank fills and padding (a panel clear, an 8..1-space right-align table); a marker in them paints garbage over whole screens. Make them data.
- references/pipeline.md §Marker: one-character "strings" can be sentinels the code copies and compares (here `≠` = empty slot in the name-entry field, r077c94); as a marker the entry fields filled with `77` and the name stored ASCII. Look at every 1-code pointered string before marking: copy/compare = data.
- references/pipeline.md §Width gate: a "same bytes = same px" budget for ROM strings is wrong where the JP font has narrow glyphs (fullwidth Latin, digits, ー at 8 px): ＶＰ is 16 px, 4 ASCII letters 24 px. Budget from the JP pixel width via the game's width table.
- references/emulator-qa.md §emu.py: `L.shot(name)` writes the name as given (no .png added), and sheet.py only picks up `f<frame>.png`; name periodic Lua shots `f%06d.png` (tools/lua/shots.lua).
- references/emulator-qa.md §jp_left: `--gba-ptrs` still reports stale copies of relocated text whose "pointer" is a chance word inside archive/graphics data or an odd (Thumb) value mid-string; check each slot holds an even string start before treating it as real.
- scripts/sheet.py: `--out DIR/x.png` fails with FileNotFoundError when DIR does not exist (no mkdir); create it first. Explicit PNG arguments must be named f<frame>.png too ("no f<frame>.png matched").
- references/emulator-qa.md §Visual QA: a dialogue box caught mid line-scroll shows both lines overprinted for one frame (GBA Vattroller X; the original does it too): reviewers flag it as overlap; list it as a game non-bug in the brief.
- references/graphics.md §Survey: a label-run finder that matches VRAM tiles by content maps identical tiles to the first copy (#446 has "▶けってい" twice): check a run's neighbours before redrawing.
- references/graphics.md §Survey: sprite text whose tiles are stored with the same bytes can still be missed by a finder that only matches whole sprite blocks at the OAM tile index (Vattroller X help bubbles, #437): match single 32-byte tiles (up to a colour remap) across all unpacked files; the GBA sprite animation sets here are {sheet ROM ptr, n, n, frame table} with frames {u16 0, u16 count, u32 0, ptr} - read the count from the entry before the pointer, not after.
- references/graphics.md §Lettering: GBA sprite labels can straddle two 8 px tile rows (dakuten push the kana up: Vattroller X "Ⓐ ▶つぎにすすむ" is a 32x16 + 16x16 pair with ink on rows 3-11); a one-row label redraw misses them, compose the blocks into one canvas and redraw an 8-row strip of it.
- scripts/tiles.py: `render --len` is ignored (always renders the whole file); crop the output with sheet.py instead.
- references/emulator-qa.md §Visual QA: the qa_codex-style verdict runner should append each verdict as it arrives; a run killed for low memory lost a whole chunk's verdicts when the output was written only at the end.
- references/emulator-qa.md §Text coverage: an interpreter-redirect sweep (Lua hook at the script step entry, rewrite the command pointer through every box-open/text/close/choice command in order) covers 11k+ event lines in ~25 frames each; the textcover probe over the whole GBA ROM (`8000000-91CBFC0`) is fast enough. Paths passed in `--var` to Lua must be absolute (Mesen runs from its own dir). A new tour after any build change re-hashes nearly every sheet (timing shifts), so verdicts rarely carry over; Mesen GBA uses ~1.1 GB per instance, and Claude Code reaps background runs under memory pressure: run codex verdicts and emulators one at a time.
